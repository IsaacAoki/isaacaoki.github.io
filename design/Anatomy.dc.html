Anatomy of a helix that never stops turning

Viewed straight on, a rotating helix and a vertically travelling helix are the same picture. That equivalence is what makes this cheap enough to run forever.

Geometry

x₁(y) = cx + A · sin(2πy/P + φ)
x₂(y) = cx + A · sin(2πy/P + φ + π)
z (y) = cos(2πy/P + φ) → depth, −1 … +1

φ advances forever. Because φ only shifts the wave along y, one full turn is a translation of exactly P — so the loop is seamless and the whole layer can be a single GPU-composited transform. No per-frame redraw, no canvas, no JavaScript in the render path.

Depth is the whole illusion

Without these four rules the drawing reads as a flat ribbon sliding upward, not a cylinder turning.
