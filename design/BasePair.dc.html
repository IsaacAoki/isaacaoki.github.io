Sheet 02 gets the strands turning by translating them. A rung that carries a title cannot travel — it has to stay level with its row. So the rungs are pinned, and the phase is handed to them instead.

EACH ROW'S DELAY = −(y / P) × 16 s
SO THE COLUMN READS AS ONE HELIX, NOT FIVE LOOSE BARS

The whole trick
.pair { transform-origin: center; animation: pair 16s linear infinite; } /* per row, set once at build time */ style="animation-delay: -{{ y / P * 16 }}s"

A negative delay starts the animation already in progress, so every rung sits at the phase its position demands — without a scroll listener, a timer, or a single frame of JavaScript. Rows added later inherit it from their own y.
